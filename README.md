# 📬 Outlook キーワードビルダー

Outlookの**メール検索**・**自動振り分けルール**に使う文字列を正確に組み立てるブラウザツールです。  
インストール不要・API不要・ローカル完結で動作します。

---

## 使い方

`outlook-keyword-builder.html` をダウンロードし、ブラウザで開くだけです。

---

## 機能概要

### 🔍 検索ボックス用タブ
Outlookの検索ボックスに貼り付けるクエリを作成します。

| 機能 | 内容 |
|---|---|
| キーワード入力 | 最大3つまで入力可能 |
| 完全一致トグル | ONにすると `"キーワード"` でダブルクォート囲み |
| OR / AND / NOT | キーワード間の演算子を選択 |
| 自動生成 | 入力と同時にリアルタイム生成 |
| コピー | ワンクリックでクリップボードへ |

**Outlookの検索書式**

```
"営業 田中"              # 完全一致（スペース含む）
"請求書";"見積書"        # OR（セミコロン区切り）
"報告" AND "10月"        # AND
"報告" NOT "日報"        # NOT
```

---

### 📂 振り分けルール用タブ
仕分けウィザードの「文字の指定」ダイアログに入力する文字列を作成します。

| 機能 | 内容 |
|---|---|
| 条件キーワード | 最大3つ、OR/AND選択可能 |
| 除外キーワード | 例外条件（〜を含まない）を2つまで設定 |
| 条件・除外を別出力 | コピーボタンを分けて表示 |
| フリーメールドメイン | 個人メール用ドメインをチップから選択 |

**Outlookの振り分けルール仕様（重要）**

- 「文字の指定」ダイアログで「追加」を繰り返すと **OR条件** で複数キーワードを一括登録できる
- 同一件名内のAND検索は非対応。AND条件はウィザードで「複数の条件にチェック」することで実現
- 差出人のアドレス条件ではドメイン（`@gmail.com` など）を指定するのが効果的

### 🛒 通販スタッフ向けタブ
農業資材EC向けの推奨ルール設計ガイドラインです。キーワードはタップでコピーできます。

#### 推奨フォルダ構成

```
受信トレイ
├─ 📦 楽天_全受信        ← 最優先（上流）
│   ├─ 👤 楽天_お客様対応
│   └─ 🔔 楽天_自動通知
├─ 👤 お客様対応          ← フリーメール・直接メール
├─ 💴 見積依頼
├─ 🏢 取引先
└─ 📦 メーカー通知
```

#### ルール設計の考え方

**① 楽天メール（最優先）**  
楽天のアドレスは `@v7.rakuten.ne.jp` 等に暗号化されるため、ドメインでまず全受信。  
そこから下流ルールで「お客様対応」と「自動通知」に2段階振り分けするのが効果的。

```
差出人に含む: @rakuten.co.jp / @v7.rakuten.ne.jp / @rakuten.ne.jp
→「楽天_全受信」フォルダへ

  └─ 件名・本文に含む: お問い合わせ / 注文番号 / あんしんメルアドサービス
     →「楽天_お客様対応」へ

  └─ 除外（例外条件）: 注文内容ご確認 / 発送完了 / メルマガ / 【楽天】
     →「楽天_自動通知」へ
```

**② お客様対応（フリーメール）**  
個人からの直接メールはフリーメールドメインで捕捉。迷惑メールは別途Outlookのフィルターで対処。

```
差出人に含む（ドメインごとに1ルール）:
  @gmail.com / @yahoo.co.jp / @icloud.com / @docomo.ne.jp 等
→「お客様対応」フォルダへ
```

**③ 見積依頼（本文条件）**  
見積依頼は件名より本文中に書かれることが多い。「本文にテキストが含まれる場合」の条件を使用。

```
本文に含む（追加で一括OR登録）:
  見積 / お見積り / 見積書 / 価格を教えて / quotation / estimate 等
→「見積依頼」フォルダへ
```

**④ 取引先・仕入先**  
会社ドメイン（`@取引先名.co.jp`）で設定。同じフォルダでよければ「追加」で複数まとめられる。

**⑤ メーカー特有パターン**  
件名の書き方に特徴があるメーカーは件名条件で個別設定。  
例：`【出荷案内】` `【欠品】` `【価格改定】` `【入荷予定】`

## 迷惑メールについて

フリーメールドメインルールには迷惑メールが混入する場合があります。  
**Outlookの迷惑メールフィルターは仕分けルールより先に動作**するため、別レイヤーで管理できます。

```
受信
  ↓
① 迷惑メールフィルター（先に判定）
  ↓ 通過したもののみ
② 仕分けルール（フリードメイン → お客様対応フォルダへ）
```

漏れてくる迷惑メールは差出人を右クリック →「受信拒否リストに追加」で個別対処が現実的です。
